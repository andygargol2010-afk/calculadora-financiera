# Calculadora de interés compuesto

Aplicación React + Vite + Tailwind CSS para calcular interés compuesto y métricas financieras.

## Servidor de desarrollo

Se puede ejecutar con Vite de la forma habitual:

- `npm install`
- `npm run dev`

## Archivos clave

- `src/App.tsx` - componente principal
- `src/main.tsx` - punto de entrada
- `src/index.css` - estilos globales y Tailwind
- `package.json` - dependencias y scripts
- `vite.config.ts` - configuración de Vite
- `.mise.toml` - versiones de Node.js y pnpm

## Estilo

La aplicación usa Tailwind CSS v4 y se carga con el plugin de Vite.
